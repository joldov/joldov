Things I've built

Tokenizer efficiency across languages How much more it costs an LLM to read Mongolian than English.

Measured how efficiently 6 tokenizers (GPT-4, GPT-4o, Llama-3, Mistral, mBERT, NLLB-200) encode 5 languages using FLORES-200 parallel data. Mongolian was the least efficiently tokenized language for every model, needing up to 3.74× more tokens than English for identical content. The gap is far smaller in tokenizers built for multilingual coverage (NLLB-200), which suggests it's a solvable design choice rather than an inherent limit.

Python, Hugging Face Transformers, tiktoken, FLORES-200, pandas, matplotlib
