# Jessica Oldov — Portfolio

My personal portfolio site for 2026!

**Live site:** [here](https://joldov.github.io/joldov/)

## Stack
Plain HTML, CSS, and JS.

## Files
- `index.html` — page content
- `style.css` — styling
- `script.js` — highlights the active section in the nav while scrolling
- `images/resume.pdf` — résumé

## Run locally
Open `index.html` in a browser, or serve it properly:
```
python3 -m http.server
```

## Deploy
Push to `main` — GitHub Pages redeploys automatically.
